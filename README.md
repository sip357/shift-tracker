# Shift Plan vs Actual Tracker

## Overview
This project compares planned production tonnage against actual tonnage across operational zones and shifts.

## Features
- Reads Excel sheets using pandas
- Merges plan and actual data
- Calculates production variance
- Saves data to SQLite
- Generates variance chart
